# Official EDSML Pre-induction Checklist

This file tracks only tasks requested on Imperial College London's 2026/27
EDSML pre-induction site. It is separate from the optional personal projects in
`ROADMAP.md`.

The course is scheduled to start formally on 28 September 2026.

## Requested before arrival

- [ ] Read and revise the official Python material.
- [ ] Read and revise the official mathematics material, using the sample
      questions to identify gaps.
- [x] Create and use the GitHub account with the username supplied by Imperial.
- [ ] Complete the official `introduction-to-python` exercises.
- [ ] Complete the Imperial-modified Software Carpentry Git lessons.
- [ ] Complete the linked Software Carpentry Bash shell lessons.

## Python submission timing

- [ ] Complete compulsory lectures 1-5; lecture 6 is optional in the public
      exercise repository.
- [ ] Receive the official submission repository and instructions during
      induction week.
- [ ] Submit the requested Python exercise work by 3 October 2026.

Imperial states that submission details will be provided on 30 September. Do
not assume this personal repository replaces the official repository.

## Mathematics coverage

- [ ] Linear algebra: vectors, matrices, systems, determinants, inverses, and
      eigenvalues/eigenvectors.
- [ ] Calculus: differentiation, integration, extrema, and Taylor series.
- [ ] Vector calculus: partial derivatives, gradients, and total derivatives.
- [ ] Differential equations: ODEs and introductory PDEs.
- [ ] Statistics and probability.
- [ ] Supporting algebra, trigonometry, geometry, and numerical methods where
      confidence is weak.

## Useful but not compulsory deliverables

- [ ] Confirm that the presessional JupyterHub account works.
- [ ] Complete the short Linux command-line practice test.
- [ ] Review GitHub Hello World and Markdown guidance.
- [ ] Choose relevant items from the presessional reading list; it is a
      reference list, not a requirement to read every book.
