# Week 6: Environmental Machine Learning

## Deliverables

- `environmental_ml.ipynb`
- `report.md`

## Checklist

- [ ] Define a prediction target and a leakage-safe train/test split.
- [ ] Build a simple climatology, persistence, or linear baseline.
- [ ] Train at least two ML models.
- [ ] Use preprocessing fitted only on training data.
- [ ] Report MAE/RMSE and one domain-appropriate diagnostic.
- [ ] Compare models against the baseline, not only against each other.
- [ ] Analyse errors across time, location, or environmental regime.
- [ ] Document limitations and reproducibility.
