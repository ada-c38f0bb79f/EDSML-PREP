# Week 8: EDSML Research Portfolio

## Deliverables

- A polished root `README.md` describing the portfolio.
- Five selected, fully reproducible core notebooks.
- `research_ideas.md` with project directions.

## Checklist

- [ ] Select five notebooks that show distinct skills.
- [ ] Restart and run each selected notebook from top to bottom.
- [ ] Remove dead code, accidental outputs, and unexplained experiments.
- [ ] Add research question, method, results, limitations, and references to
      each notebook.
- [ ] Confirm figures have labels, units, legends, and readable captions.
- [ ] Confirm dependencies and data-access instructions.
- [ ] Add links from the root README to each selected artifact.
- [ ] Run tests and perform a clean-environment reproduction check.

## Suggested five-notebook set

1. Environmental Xarray/NetCDF analysis (Week 2).
2. Numerical conditioning experiment (Week 3).
3. Heat-equation stability experiment (Week 4).
4. Diffusion inverse problem (Week 5).
5. Environmental ML or PINN comparison (Week 6 or 7).

Week 8 is primarily documentation and curation rather than another external
course. Reuse the official sources cited in the earlier week directories.
